## 🌟 نظرة عامة على المشروع (Overview)
مشروع **Course Editoer** هو تطبيق ويب مصمم خصيصاً لتسهيل إدارة الكورسات والعمليات التعليمية. يتيح النظام إمكانية التحكم الكامل للمشرفين (Admins) بالإضافة إلى واجهات سلسة للمستخدمين العاديين لتصفح الكورسات والاشتراك فيها.

## ✨ المميزات الأساسية (Features)
* 🔐 **نظام مصادقة متكامل:** تسجيل الدخول، إنشاء حسابات جديدة، وتأمين كلمات المرور.
* 👨‍💻 **لوحة تحكم المشرف (Admin Dashboard):** إضافة، تعديل، وحذف الكورسات وإدارة المستخدمين.
* 👥 **واجهة المستخدم (User Interface):** تصفح الكورسات المتاحة، تفاصيل الكورس، وطرق الدفع المختلفة (مثل PayPal و Visa).
* 🗄️ **قاعدة بيانات خفيفة وسريعة:** استخدام SQLite لإدارة البيانات بكفاءة.
* 📱 **تصميم متجاوب:** يعمل بسلاسة على مختلف الشاشات والأجهزة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Backend:** Python, Flask
* **Database:** SQLite, SQLAlchemy (Model)
* **Frontend:** HTML5, CSS3, JavaScript
* **Tools & Environment:** Git / GitHub, VS Code
